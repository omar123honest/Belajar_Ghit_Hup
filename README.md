# 📘 Git Command & Istilah Developer IT

Dokumentasi referensi (dalam Bahasa Indonesia) berisi kumpulan istilah kerja tim IT sehari-hari beserta panduan lengkap perintah Git — dari dasar sampai lanjutan, termasuk cara membaca dan menyelesaikan **merge conflict**.

Materi ini cocok dipakai sebagai bahan belajar mandiri, onboarding developer baru, maupun referensi cepat saat bekerja.

## 📂 Isi Repository

| File | Keterangan |
|---|---|
| `Git_Command_dan_Istilah_Developer_IT_(Lengkap).docx` | Dokumen utama, berisi seluruh materi di bawah ini |

## 📑 Daftar Isi Materi

**Bagian I — Istilah & Singkatan dalam Kerja Tim IT**
Review & kolaborasi kode (PR/MR/CR) • Status & alur kerja PR/tiket (WIP, LGTM, TBR, ETA) • CI/CD & UAT • Jenis tiket (POC, Hotfix)

**Bagian II — Perintah Dasar Git**
`config` • `init` • `clone` • `status` • `diff` • `add` • `commit` • `log` • `branch` • `checkout` / `switch` • `merge` • **Merge Conflict** • `remote` • `push` • `pull` / `fetch` • `rebase` • `reset` vs `revert` • `stash` • `tag` • `.gitignore`

**Bagian III — Tabel Ringkasan Perintah Git**
Cheat sheet seluruh perintah untuk referensi cepat.

**Bagian IV — Alur Kerja Git Tim**
Urutan kerja umum dari `clone` sampai merge & CI/CD.

**Bagian V — Konsep Dasar Git**
Apa itu Git vs GitHub/GitLab • Tiga area kerja (working directory, staging, repository) • Cara Git menyimpan data (snapshot) • HEAD, commit hash, folder `.git/`

**Bagian VI — Perintah Git Lanjutan**
`cherry-pick` • squash commit (`rebase -i`) • `bisect` • `submodule` • alias

**Bagian VII — Strategi & Best Practice**
Git Flow vs Trunk-Based Development • Conventional Commits • Semantic Versioning

**Bagian VIII — Troubleshooting & Autentikasi**
SSH key vs Personal Access Token • Daftar error umum dan solusinya
